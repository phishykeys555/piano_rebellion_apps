App identity sheet

Step 1 of "give every training app its own look": one label, different covers. Each app gets its own colour world, picture icon, texture and personality; layout, type, buttons, the CHMA badge and the footer stay shared. Nothing here changes any app yet. Review page only (not linked from the hub).

Shared across every app (unchanged)

  • Layout grid, type family, button shapes and sizes, the CHMA badge and header, the footer line and "Send feedback".
  • Rollout after a yes: per-app colour and texture through CSS variables in each app only, beta first, one app at a time. No change to saved settings or how any app works.
  • Skins (if approved): 2 to 3 per app, picked in the app's settings and saved as one new preference key; default stays as today.
  • Contrast: every pair below is measured (WCAG). Pairs under 4.5:1 are used only for large text or decoration.
